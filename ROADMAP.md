# Iris roadmap

## Prototype implemented

- Native desktop conversation and reactive galaxy interface.
- Scoped coordinator and three specialist roles through Hermes.
- Streaming speech transcription and generated replies.
- On-device Hey Iris detection and automatic pause-to-send.
- Explicit folder/domain grants, action approval, local persistence.

## Next

- Repeat live voice acceptance for the Iris rename on supported hardware.
- Test noisy-room wake behavior, provider disconnects, microphone changes, and interruption.
- Improve first-run setup, accessibility, and helpful recovery states.
- Measure sustained native rendering and battery/resource use.
- Add integration tests for supported Hermes upgrades.

## Later

- Expand file operations through precise previews, approvals, and rollback design.
- Add research search with explicit sources and scoped credentials.
- Develop richer coordination, task continuity, and configurable personal context.
- Plan signing, notarization, releases, and updates after prototype acceptance.

These are development directions, not delivered features or release commitments.
